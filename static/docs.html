Platform & API Reference

Integrate Error404 DOXNOSINT via the REST API or use the web console. All endpoints are free, open, and require no authentication.

Open Console Jump to endpoints

Quick Start

All endpoints are GET requests. No API key required. Base URL:

# Production
https://osint-website-production.up.railway.app

# Local development
http://localhost:8000

Quick example — look up an email address:

curl "https://osint-website-production.up.railway.app/api/email/user@example.com"

Architecture

Error404 DOXNOSINT v5.0 is built on Python 3.11 + FastAPI with a single-page vanilla JS frontend. All lookups are performed server-side using open APIs, web scraping, and DNS resolution.

RuntimePython 3.11 + FastAPI
FrontendVanilla JS SPA (no framework)
DeploymentDocker + Railway
Total Endpoints43 tool endpoints
Platform Scans160+ platforms (username scanner)
AuthNone required — fully open

Error Codes

All errors return JSON with a consistent structure.

200Success — full response payload
404Not found — endpoint does not exist
422Validation error — bad path parameter
500Server error — upstream API failure

Error response format:

{
  "detail": "Not Found"
}
